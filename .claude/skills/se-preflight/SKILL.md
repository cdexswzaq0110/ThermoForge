# Capability Doctor — 前置檢查

**Connection Pool 的取得程序。** 外部能力會換代、會被封、會過期。這個 skill 讓「換接入方式」變成調整清單順序，而不是重寫流程。

## 核心設計

**每一種能力 = 一份有序的後端清單。**

```
能力：跨模型審查
  首選 ▸ codex CLI
  備選 ▸ 平台原生 Subagent
  備選 ▸ 降級（同模型不同 context，標記 [降級]）
```

換後端 = 調整順序。呼叫端不需要知道換了什麼——但**必須被告知現在走哪一條**。

## 三條鐵律

### 1. 探測是真的跑一次，不是看命令在不在

`which codex` 回傳 0 不代表 `codex` 能用：可能沒登入、配額用完、版本太舊、在錯的環境（Windows 登入了但你現在在 WSL）。

**探測 = 執行一個最小的真實操作**，例如 `codex login status`、`gh auth status`、對 MCP server 發一次 `list_tools`。

### 2. 前置檢查一次做完，不要邊跑邊發現

在 Frame 階段（`se-scheduling` Phase 0）一次檢查完所有這一輪會用到的能力。**跑到一半才發現缺工具，等於整輪重來。**

### 3. 降級要說出來，不要靜默切換

首選失效 → 用備選，並**明說換了哪一個、為什麼**。

靜默降級最貴的地方不是效能，是**你以為你有的保證其實沒有**——例如以為兩個 Reviewer 是不同模型，實際上都降級到同一個。

## 前置檢查報告格式

```
能力            狀態    現在走           備註
──────────────────────────────────────────────────────────
Git             ✓       git 2.43         —
GitHub          ✓       gh (已認證)      —
跨模型審查      ⚠       平台 Subagent    codex 未登入 → `codex login`
瀏覽器驗證      ✓       內建瀏覽器       —
網路搜尋        ✗       無               需設定；本輪相關結論標「未驗證」
MCP: <name>     ✓       stdio            —
平台並行數      ✓       上限 <N>         —
```

三種狀態：`✓` 可用 · `⚠` 降級可用（註明降到哪、怎麼修）· `✗` 不可用（註明本輪哪些結論會因此受限）。

## 安全預設

| 原則 | 落地 |
|---|---|
| **預設不改系統** | 檢查與回報是預設行為。安裝、寫設定、改 PATH 都要**明確授權**才做 |
| **先預覽** | 有 dry-run 的先跑 dry-run，把會做的事列出來再問 |
| **憑證只在本機** | Token、Cookie 存在使用者本機，權限收到只有擁有者可讀。不上傳、不寫進 repo、不進 log |
| **憑證不經聊天框** | 使用者在對話裡貼了 key → 告訴他改用環境變數或本機設定檔，不要幫他存進檔案裡然後 commit |
| **有卸載路徑** | 裝了什麼要能拆乾淨，包含它寫到 repo 外的狀態 |

**API key 與密碼由使用者自己輸入。** 不代填、不代建帳號、不代過驗證。

## 快取探測結果

同一輪內不要重複探測。把結果記在 Frame 階段的能力表裡，後續派發直接讀。

跨輪**不要**快取——環境會變，上一輪能用不代表現在能用。真的要快取，寫一個帶時間戳的本機設定檔，並在讀取時檢查它多舊。

> 這條同時是省 token 的：每次啟動都重讀一遍工具說明是浪費。已知指令形狀就直接呼叫，只有在介面未知、呼叫失敗、或剛安裝更新時才去讀完整說明。

## 常見能力與探測方式

| 能力 | 探測 | 常見失效 |
|---|---|---|
| Git | `git --version` + `git rev-parse --show-toplevel` | 不在 repo 內 |
| GitHub | `gh auth status` | 未認證、token 過期 |
| 另一個 AI CLI | `<cli> login status` 或最小 `-p` 呼叫 | 未登入、配額、環境不對（Windows vs WSL） |
| MCP server | 列一次 tools | 未啟動、設定路徑錯 |
| 瀏覽器操作 | 開一個空白分頁 | 平台不支援 |
| 容器 | `docker info` | daemon 沒起來 |
| 語言 runtime | `<runtime> --version` | 版本太舊、多版本衝突、PATH 順序 |

**環境隔離要特別注意**：Windows 與 WSL 是兩個獨立環境。一邊登入了，另一邊不會自動生效。探測必須在**實際要執行的那個環境**裡跑。

## 完成條件

- 這一輪會用到的能力都探測過（真實操作，不是看命令存在）。
- 報告列出每個能力現在實際走哪一條後端。
- 降級的都已明說；不可用的都已註明本輪哪些結論會受限。
- 沒有在未經明確授權的情況下安裝、寫設定或改系統。
