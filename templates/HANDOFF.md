# Process 交接（IPC 訊息）

> Process 之間**不共享記憶體**。這份文字是唯一合法的傳值方式，所以它必須是**可序列化且自足**的——收到的人從零 context 開始，只讀這一份加上它指到的檔案，就能繼續。
>
> 貼到新的 Task 之後，舊 Process 就結束。**不要兩個 Process 同時活著做同一件事。**

---

```text
請在新的獨立 Task 繼續以下工作：

<要載入的 skill 或指令>

專案根目錄：<實際絕對路徑>
分支：<branch>
目前 SHA：<sha>

規格：<實際路徑>
Processes（依建議順序）：<全部實際路徑>
共享語言：<CONTEXT.md 路徑，若有>

已完成：
- <Process 編號> — <成果一句話> — <主要驗證與退出碼>

未完成：
- <Process 編號> — <Depends on 判定或原因>

目前工作樹：
<實際 git status --short 或 diff --stat 輸出>

持有中的寫入鎖：<沒有就寫「無」>

未解決的 Finding／阻擋：
- <實際內容，含證據等級。沒有就寫「無」>

已宣告的假設：
- <這一輪為了往下走而宣告的假設，以及錯了要重做什麼>

下一步：<下一個可直接執行的行動，具體到能照做>

先讀取以上檔案與目前工作樹，再依原規格繼續。
保留既有變更，不重做已完成的工作。
```

---

## 檢查（送出前）

- [ ] 所有路徑都是**實際絕對路徑**，沒有佔位符
- [ ] SHA 是剛剛實際查過的，不是印象中的
- [ ] 「下一步」具體到收件者不用再問就能開始
- [ ] 未解決的 Finding 帶著證據等級
- [ ] 宣告過的假設都列出來了（否則下一個 Process 會把假設當成事實）
- [ ] 純過渡的筆記寫到 OS 暫存目錄，**沒有進 repo**
