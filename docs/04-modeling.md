# 04 — 建模決策（Stage 3–4）

> 結果表在 [05-results.md](05-results.md)。本檔只講**為什麼這樣建模**，
> 以及每個決策是被什麼證據支持的。

## 決策一：無因次化——本專案最重要的一個

原始問題有六個會變的量（Lx、Ly、kt、h、總功率、T_amb），但方程

```
∇²θ − m²θ = −p/kt
```

只透過兩件事依賴它們：**核的寬度** 1/m 與**整體的溫度尺度**。把兩者除掉之後，
網路只需要學一個形狀函數。

兩個尺度都是**精確可算**的，不是估的：

| 尺度 | 定義 | 為什麼精確 |
|---|---|---|
| 溫度 θ_ref | P/(h·A) | 能量守恆的直接結果（絕熱邊界下 h·∫θ dA ≡ P） |
| 長度 1/m | √(kt/h) | 方程係數本身 |

於是模型的輸入是 `p_norm`（空間平均恆為 1）與 `(m·Lx, m·Ly)` 兩個無因次數，
輸出是 `θ_norm`（空間平均恆為 1）。實測驗證：`θ_norm` 的逐樣本空間平均
偏離 1 最多 4.5e-9，往返轉換誤差 2.3e-13【已確認：2026-09-07】。

### 它應該買到什麼

θ 對功率**線性**，除以 θ_ref 之後功率就完全消失了。所以做完無因次化的模型
在 `ood_power` 上的表現，理論上應該與 id 相同——**功率外推從學習問題變成恆等式**。

### 為什麼還要跑 `direct` 對照組

上面那段在紙上一定對。但「聽起來一定對」不是證據，而且它有兩個可能的失敗方式：

1. 網路可能學不到無因次表示的好處（例如 FiLM 條件化把 m·L 傳得不夠好）。
2. `direct` 可能靠著記住訓練分佈的統計量就達到差不多的分數，
   讓無因次化在 id 上看起來沒有價值——**而真正的差距只在 OOD 出現**。

所以 `direct`（原始功率圖 ＋ 用 training fold 統計量標準化的 kt/h/Lx/Ly）
與 `norm` 用**同一個網路、同一份 folds、同一組超參數**跑，只差輸入與目標的定義。
兩行的差距就是這個決策實際值多少。

## 決策二：學殘差，不是學整個場

物理基準（Green's ＋ 一階鏡像）在無因次座標系裡可以直接算出來
（`baselines.greens_theta_norm`，與有因次版本逐點一致到 7e-16【已確認】）。
於是 `residual` 變體把目標改成 `θ_norm − greens_norm`，輸入多一個 greens 通道。

理由不是「殘差比較小所以比較好學」——那個說法對線性模型成立，對神經網路不一定。
真正的理由是**誤差的結構**：物理基準已經對了長程的擴散行為，剩下的誤差集中在
邊界附近與元件之間的交互作用，那是空間局部的、卷積網路擅長的東西。

這仍然是假設。`norm` 與 `residual` 的差距就是它的證據。

## 決策三：FiLM 條件化，不是廣播成通道

`m·Lx` 決定的是**核有多寬**——一個全域的、乘性的效應。廣播成一張常數圖之後，
網路要從空間卷積裡把一個常數重新萃取出來。FiLM 讓它直接調變每個通道的增益，少繞一圈。

這是選擇不是定論，而且**沒有單獨做消融**——`direct` 變體用的是廣播通道，
但它同時也沒有無因次化，所以兩個因素混在一起。
**這是本專案已知的一個歸因缺口**，記在 [05-results.md](05-results.md) 的殘留風險。

## 架構與訓練

| 項目 | 值 |
|---|---|
| 網路 | 三層下採樣 U-Net，base 32 通道，GroupNorm ＋ SiLU，FiLM 條件化 |
| 參數量 | 0.91 M【已確認】 |
| 損失 | L1（`under_weight` 開關可改成對低估加權，見下） |
| 最佳化 | AdamW，OneCycle，max_lr 2e-3，weight decay 1e-4 |
| epochs / batch | 25 / 32 |
| 裝置 | RTX 3060 12GB |

### 不對稱損失是一個實驗，不是預設

問題定義第 5 題就寫下「低估比高估貴」，而 L1 對兩側一視同仁。
`under_weight=3.0` 對低估側加權，是 Stage 5 的一個獨立實驗——
**預設關閉**，因為「加權會改善決策」在跑之前只是一個假設，
而它有明顯的代價（整體 MAE 會變差）。結果見 [05-results.md](05-results.md)。

## Gate 2：Pipeline

| 檢核 | 證據 |
|---|---|
| 可在 raw-like 輸入上 fit/predict，不需要預先 fit 的外部物件 | `Predictor.fit(Dataset)` → `predict(Dataset)`；`evaluate.run_oof` 每個 fold 重建預測器 |
| fit 型處理只在 training fold | `direct` 的四個統計量在 `NeuralPredictor.fit` 內算；其餘變體不含任何 fit 型統計量 |
| 序列化後預測一致 | `save`/`load` 一併存超參數與正規化常數（少了它們 `direct` 會用錯的常數推論而不報錯） |
| 單列 batch 可跑 | `dataset.from_layouts([layout])`，設計副駕走的就是這條路徑 |

物理基準場整批預先算好（`thermoforge.precompute_greens`）**不構成 leakage**：
它是一個解析公式，不含任何從資料估出來的參數，所以「全體先算」與
「training fold 內算」得到同一個值。判準只有一條——**它有沒有 fit 任何東西**。

## Gate 3：改善要大於噪音

每個 run 都回報五個 fold 各自的 Tmax MAE 與它們的標準差（`oof_fold_noise_std`），
並且關鍵比較各跑兩顆 seed。判準：

- 改善必須**大於 fold 間的標準差**，否則視為未證實。
- 改善若只在一顆 seed 出現 → **拒絕**（`se-ml-lifecycle` Stage 5 診斷表）。

實際數字與判定見 [05-results.md](05-results.md)。
