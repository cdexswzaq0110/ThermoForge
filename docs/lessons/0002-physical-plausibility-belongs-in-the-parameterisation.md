# 合成資料的物理合理性要在**參數化**裡解決，過濾樣本會把 target 洩進切分

## 觸發情境

自己生成訓練資料（模擬器、程序化取樣、資料增強），而生成出來的樣本
有一部分在領域上明顯不合理——溫度上千度、價格是負的、速度超過光速那一類。

## 領悟

**修法有兩條，看起來等價，實際上一條會毀掉驗證設計。**

本專案第一版獨立抽總功率 P 與對流係數 h。跑出來的熱點溫度
中位數 104 °C、p99 314 °C、最大 1087 °C【已確認：2026-09-07 實測分佈】。
沒有材料在 1087 °C 下還是一塊 PCB，而那些樣本會直接主導 field MAE。

| 修法 | 後果 |
|---|---|
| **過濾**：算出溫度，丟掉太熱的樣本 | 這是**對 target 做篩選**。訓練與驗證集都變成「條件溫和的那一半」，而推論時遇到的不是。分數會樂觀，且樂觀的幅度量不出來 |
| **換參數化**：先抽目標熱點溫升，用只吃輸入的解析估計回推功率 | 定義的是設計空間，不是篩掉結果。分佈換了，但每個抽出來的樣本仍然是完整的一次「條件 → 結果」 |

第二條的關鍵條件：那個解析估計**只能用推論時拿得到的量**。用求解器算一次
再回頭調參數就退化成第一條了，只是繞了一圈。

修完的分佈：中位數 89.1 °C、p99 149.4 °C、最大 179.8 °C。

## 為什麼會撞到

錯誤假設是：**合成資料沒有選擇偏誤，因為是我自己生成的。**

真相相反——合成資料的選擇偏誤是**取樣器的每一行程式碼**。真實資料的偏誤來自
世界，看得到、查得到；合成資料的偏誤來自你自己的 `rng.uniform(...)`，
而那看起來像是「中立的」。

具體的陷阱是**獨立抽相依的量**。P 與 h 在物理上不獨立：真實產品的功率預算
是配合散熱能力訂的。獨立抽就會在角落生出「高功率 ＋ 弱散熱」這種
物理上不存在的組合，而那個角落的樣本因為極端，會主導所有以平均為基礎的指標。

## 下次怎麼做

生成資料之後，**先看 target 的分佈，再看它的極端值在領域上存不存在**。
存在就留著，不存在就往回改**參數化**：

1. 找出哪兩個獨立抽的量在領域上其實相依。
2. 改抽那個**有領域意義的合成量**（這裡是熱點溫升；在定價可能是毛利率；
   在排程可能是負載率），再回推原始參數。
3. 回推用的公式**只能吃推論時拿得到的輸入**。這一條要寫進取樣器的 docstring，
   因為六個月後回來看，那個公式長得跟一個 target 洩漏一模一樣。
4. 把「為什麼改參數化而不是過濾」寫進資料契約文件——這是 reviewer 一定會問的。

## 失效條件

- 資料改成真實量測——那時的偏誤來源是量測與抽樣流程，這一則的機制不適用，
  但「先看 target 分佈的極端值」那一步仍然成立。
- 領域本身允許那些極端值（例如刻意研究失效模式的資料集）——那時 1087 °C
  不是缺陷而是研究對象。判準是「這個樣本代表的情境會不會出現在推論時」。
